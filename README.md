📊 Customer Lifetime Value (CLV) & Segmentation EngineAn end-to-end machine learning product and interactive dashboard that combines unsupervised customer segmentation with supervised predictive regression to help retail marketing teams target high-value customers, prevent churn, and optimize promotional budgets.🎯 Overview & Business ProblemTraditional online retailers often treat every customer the same, leading to wasted marketing spend and poor retention. This project bridges data science and marketing strategy by:Segmenting customers using behavioral RFM (Recency, Frequency, Monetary) metrics and K-Means clustering.Predicting future value by training a supervised regressor to forecast each customer's exact 90-day spend with a strict time-based split to prevent data leakage.Delivering insights through an interactive Streamlit marketing dashboard designed for non-technical stakeholders.🚀 Key FeaturesRobust Data Pipeline: Handles heavy data cleaning (removes missing Customer IDs, filters out cancellations/returns starting with 'C', validates positive quantities/prices).RFM Feature Engineering: Computes Recency, Frequency, and Monetary scores within an observation window.Time-Based Cut-Off Split: Simulates real-world deployment by cutting off data 90 days prior to the max date to generate true out-of-sample prediction targets ($y$).Unsupervised Clustering & PCA: Groups buyers using K-Means ($K=4$) and projects high-dimensional behaviors into a 2D PCA scatter plot.Supervised CLV Regression: Employs a Random Forest Regressor to predict next-90-day spend ($R^2 \approx 0.90$).Interactive Dashboard: Built with Streamlit and Plotly to search customer profiles, review segment KPIs, and surface actionable marketing strategies.📁 DatasetSource: Online Retail II Dataset (UCI Machine Learning Repository)Description: Contains ~1 million real retail transactions spanning from 2009 to 2011 across two workbook sheets (Year 2009-2010 and Year 2010-2011).🏗️ Project Structure├── app.py                             # Streamlit interactive dashboard
